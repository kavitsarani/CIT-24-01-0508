# Virtualization Lab 6

This repository contains the Kubernetes manifests, screenshots, and checkpoint answers for the Lab 6 virtualization exercise.

## What is included

- Kubernetes YAML files under Lab06/k8s for the frontend, API, cache, database, and supporting services
- Screenshot files under Lab06/Screen Shots showing the lab workflow and results
- Checkpoint answers in ANSWER.md

## Project structure

- Lab06/k8s/ - deployment and service manifests
- Lab06/Screen Shots/ - lab screenshots
- ANSWER.md - full answers to the nine checkpoints

## Notes

This lab focuses on Kubernetes concepts such as Pods, Deployments, StatefulSets, Services, rolling updates, persistence, and control-plane versus worker-node roles.
